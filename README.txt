RECAP STUDIO MM - STARTER PROJECT

ဒီ project က RecapKit လို workflow ကို reference ယူထားတဲ့ ကိုယ်ပိုင် UI prototype ဖြစ်ပါတယ်။

ပါဝင်သည်:
- Video upload + browser preview
- Language / style / length ရွေးချယ်ခြင်း
- AI processing demo
- Recap script area
- Voice/subtitle options
- Export button
- Mobile responsive design

တကယ့် AI website ဖြစ်အောင် နောက်ထပ်လိုအပ်သည်:
1. Backend server
2. Video storage
3. Speech-to-text API
4. AI text generation API
5. Text-to-speech API
6. FFmpeg video rendering
7. User login/database
8. Hosting/domain

အလွယ်ဆုံးစမ်းရန်:
- index.html ကို Chrome နဲ့ဖွင့်ပါ။
- Video တင်ပြီး "AI Recap စတင်မည်" ကိုနှိပ်ပါ။

Online တင်ရန်:
- GitHub Pages / Netlify / Vercel တို့တွင် frontend ကိုတင်နိုင်သည်။
- AI processing ပါတဲ့ production version အတွက် backend server လိုပါမယ်။
